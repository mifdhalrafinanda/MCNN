# 🧑‍🤝‍🧑 Crowd Counting with Multi-Column CNN (MCNN)

**A deep learning-based crowd counting system that achieves higher accuracy in real-world scenarios.**

This project focuses on improving a crowd counting system using the **Multi-Column Convolutional Neural Network (MCNN)**. The model is specifically designed to handle variations in crowd appearance — such as people appearing larger or smaller in images due to camera distance and perspective distortion.

The model was evaluated on multiple public datasets, demonstrating relatively low estimation error, with particularly strong performance on the **Nol KM dataset**. These results indicate that the approach is highly effective for real-world crowd counting applications.

---

## ✨ Key Features

- **Multi-scale feature extraction** — Multiple CNN columns with different receptive fields to handle dense, sparse, near, and far crowds.
- **Robust to perspective changes** — Effectively reduces errors caused by camera angle and distance variations.
- **High accuracy on real-world data** — Thoroughly tested on public benchmark datasets.
- **Best performance on Nol KM dataset** — Proves strong generalization for practical use cases (surveillance, smart cities, event management, etc.).

---

## 📊 Evaluation Results

The system estimates the number of people in an image with relatively low error across several public datasets. The lowest error rates were observed on the **Nol KM dataset**, confirming the effectiveness of the improved MCNN approach for complex, unstructured crowd scenes.
